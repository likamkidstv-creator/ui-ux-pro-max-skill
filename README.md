## Overview

Official website for the Ottawa Bolides Soccer League (OBSL), a multicultural grassroots soccer community serving the Ottawa-Gatineau region since 2007.

## Features

- League standings and statistics
- Match schedules and results
- Top scorers and league leaders
- Club directory with all 14 participating teams
- Mobile-responsive design with dark theme

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui components
- Framer Motion animations
